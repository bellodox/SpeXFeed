Configure SpeXFeed with a local ROD wallet

SpeXFeed desktop uses a local helper service for ROD name lookups, profile-name registration, updates, and relay seed recovery. Keep your ROD wallet on your machine; the app talks to the helper API instead of exposing wallet credentials in the browser UI.

account_balance_wallet

1. Start ROD Core RPC

Run your local ROD node with RPC enabled and reachable at localhost:11999. Match the RPC user and password to your local ROD configuration.

folder_shared

2. Load the SpeXFeed wallet

Create the app wallet once with createwallet spexfeed, then load it with loadwallet spexfeed before submitting registrations or updates.

settings_ethernet

3. Configure the helper

Copy server/.env.example to server/.env, then set ROD_RPC_USER, ROD_RPC_PASSWORD, ROD_RPC_HOST, ROD_RPC_PORT, ROD_WALLET_NAME=spexfeed, and SERVER_PORT=3000.

Start the helper service before opening the desktop app. If SpeXFeed reports wallet or RPC setup errors, verify that the ROD node is synced, the spexfeed wallet is loaded, and the helper credentials match your local ROD RPC settings.

Relay seed recovery shipped for alpha testing

SpeXFeed now includes the ROD blockchain relay seed registry MVP for relay partition recovery: a helper endpoint, sf.relays.v1 validation, frontend seed lookup, bootstrap relay merging, and a manual "Import Blockchain Seeds" action on the Relays page.

The release also adds helper .env setup for ROD RPC credentials, wallet name, wallet passphrase, and helper server port. The first sf/relays-global registry record has been submitted and remains pending mining before full production-style verification.
